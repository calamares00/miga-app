# Icons with depth (proposals)

`propuestas.png` shows the 16 proposals; each one is also here alone at 512×512 (`NN_glyph_theme.png`).
Android-style squircles with gradient backgrounds, soft shadow, shine and grain, so they do not look
flat. Themes: terracota, huerta, teal, atardecer, noche, crema, uva, limón. `make.py` writes the HTML
they were rendered from (Playwright); any glyph can take any theme.
