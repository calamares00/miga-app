What's new in version 1.0.52:
• Fixed: the app closed when opening Favourites if you followed two sections of the same website sharing recipes. Each recipe now shows only once.
• Favourites no longer hides some English recipes (such as croquettes) by mistake.
• When following, Miga warns if you already follow another section of the same website, and if a channel, profile or website doesn't seem to be about cooking (you can follow it anyway).
