What's new in version 1.0.53:
• Choose which server books you want on each phone, in Settings › Sync server › Server books. The rest take no space or data. When joining a server you choose before anything is downloaded.
• Deleting a synced book only removes it from this phone: it stays on the server and on the others. To delete it for everyone, use the server's web admin.
• Needs miga-server 1.3.0 or later.
